Supabase Database Migration (PostgreSQL)

Hệ thống đã xây dựng trọn bộ 10 file SQL migration và bộ dữ liệu Seed đầy đủ tại thư mục supabase/:

  • 001_create_profiles.sql - Bảng tài khoản & trigger phân quyền
  • 002_create_patients.sql - Bảng bệnh nhân (Data minimization)
  • 003_create_specimens.sql - Mẫu bệnh phẩm & danh mục động
  • 004_create_organisms.sql - Danh mục vi khuẩn & phân loại Gram
  • 005_create_antibiotics.sql - Danh mục kháng sinh & nhóm thuốc
  • 006_create_cultures.sql - Kết quả nuôi cấy & định danh
  • 007_create_ast_results.sql - Bảng kháng sinh đồ (S/I/R, MIC, disk zone)
  • 008_create_import_jobs.sql - Quản lý file import & error log
  • 009_create_audit_logs.sql - Nhật ký an ninh & danh mục khoa
  • 010_create_rls.sql - Chính sách bảo mật Row Level Security
  • seed_data.sql - Dữ liệu mẫu 100 BN, 150 bệnh phẩm, 200 nuôi cấy, 1,000 AST
